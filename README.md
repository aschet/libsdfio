# libsdfio

[![CI](https://github.com/aschet/libsdfio/actions/workflows/ci.yml/badge.svg)](https://github.com/aschet/libsdfio/actions/workflows/ci.yml)

A portable C library that reads and writes ISO 25178-71 SDF surface data files:
the revisions ISO-1.0 and ISO-2.0, in ASCII or binary format.

The [API reference](https://aschet.github.io/libsdfio/) documents the
interface and how to build the library, and the [examples](examples) show how to
use it.
