# libsdfio

[![CI](https://github.com/aschet/libsdfio/actions/workflows/ci.yml/badge.svg)](https://github.com/aschet/libsdfio/actions/workflows/ci.yml)

A C11 library without dependencies that reads and writes ISO 25178-71 SDF surface
data files: the revisions ISO-1.0 and ISO-2.0, in ASCII or binary format.

See the [API reference](https://aschet.github.io/libsdfio/) for the interface and
for building and installing the library, and [examples](examples) for usage.
